Welcome to Tickitz! 🎬 Your ultimate cinema booking companion that brings the magic of movies right to your fingertips. Experience seamless ticket booking with our intuitive platform designed for movie enthusiasts who value convenience and efficiency. From browsing the latest blockbusters to selecting your perfect seats, Tickitz transforms the traditional cinema experience into a modern, hassle-free journey.

Built with cutting-edge web technologies, our platform offers lightning-fast performance and a responsive design that works flawlessly across all devices. Whether you're planning a romantic date night or a fun outing with friends, Tickitz ensures your movie experience starts the moment you visit our site.

This project serves as the frontend for the [Tickitz Cinema Booking Backend](https://github.com/FebryanHernanda/Tickitz-web-app-BE), delivering a complete cinema booking solution built with React.js as the frontend library, JavaScript for dynamic functionality, and Redux for seamless state management across the entire application.

## ✨ Key Features

- **Movie Discovery**: Browse trending movies with detailed information, trailers, and ratings
- **Smart Booking**: Select cinemas, showtimes, and seats with real-time availability
- **User Profiles**: Manage bookings, view history, and save favorite cinemas
- **Responsive Design**: Optimized experience across desktop, tablet, and mobile devices

## 🛠 Tech Stack

- **Frontend Framework**: React.js with functional components and hooks
- **Styling**: Tailwind CSS for modern, responsive design
- **State Management**: Redux Toolkit for efficient global state handling
- **Authentication**: JWT-based secure user authentication
- **API Integration**: Axios for seamless backend communication
- **Routing**: React Router for smooth navigation experience

## 🗝️ Environment

```bash
# Base url for backend

VITE_API_URL=<backend_address>

```

## ⚙️ Installation

1. Clone the project

```sh
$ https://github.com/FebryanHernanda/tickitz-web-app-react.git
```

2. Navigate to project directory

```sh
$ cd tickitz-web-app-react
```

3. Install dependencies

```sh
$ npm install
```

4. Run project

```sh
$ npm run dev
```
